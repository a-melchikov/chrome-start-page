# Дизайн прозрачных виджетов Liquid Glass

Дата: 2026-09-03

## Цель

Сделать поверхности Markdown- и Search-виджетов полупрозрачными, чтобы через
них были видны выбранные обои или цвет фона. Эффект должен напоминать статичное
стекло в интерфейсах iPhone, сохранять читаемость контента и отключаться одной
настройкой.

## Область изменений

Эффект применяется только к пользовательским виджетам:

- карточке Markdown;
- компактной поисковой строке Search.

Верхняя панель управления, диалоги и остальные поверхности интерфейса не
меняются. Анимация блика, реакция на курсор и регулировка отдельных параметров
эффекта не входят в задачу.

## Внешний вид

Liquid Glass состоит из фиксированного набора CSS-эффектов:

- сбалансированный полупрозрачный tint;
- размытие, насыщение и небольшой контраст подложки через `backdrop-filter`;
- мягкий световой градиент;
- тонкая полупрозрачная рамка;
- внутренняя подсветка верхней грани;
- мягкая внешняя тень для отделения от обоев.

Светлая тема использует светлый tint и тёмный текст, тёмная — затемнённый tint
и светлый текст. Значения различаются по теме, чтобы содержимое оставалось
читаемым на светлых и тёмных обоях. Если браузер не поддерживает размытие
подложки, прозрачный tint, рамка и тень сохраняются как fallback.

При отсутствии обоев эффект остаётся включённым и отображается поверх
выбранного цвета фона.

## Поведение виджетов

Markdown сохраняет текущую геометрию, внутренние отступы, прокрутку и структуру
заголовка. Меняется только оформление внешней карточки.

Search остаётся bare-виджетом без заголовка и высотой в одну строку. При
включённом эффекте форма становится единой стеклянной капсулой, а поле ввода —
полупрозрачной внутренней поверхностью. Кнопка с локальным логотипом поисковика
остаётся контрастной. При выключенном эффекте Search возвращается к прежнему
виду без внешней капсулы.

## Настройка оформления

В диалоге «Оформление» появляется четвёртый изначально закрытый раздел
«Виджеты». В нём находится один переключатель «Эффект Liquid Glass».

Настройка:

- включена по умолчанию;
- применяется сразу;
- сохраняется немедленно;
- не содержит ползунков прозрачности, размытия или других параметров;
- сохраняет текущее правило: при каждом открытии диалога все разделы закрыты.

При выключении Markdown возвращается к прежней непрозрачной карточке, а Search
— к прежнему виду без внешней стеклянной поверхности.

## Архитектура

В `AppearanceConfig` добавляется булево поле `liquidGlassEnabled`. Версия
сохраняемой схемы повышается с 3 до 4. Конфигурации v1, v2 и v3 мигрируют в v4
с `liquidGlassEnabled: true`, не теряя виджеты, обои, тему, цвет фона и layout.

`App` применяет к корневой поверхности единый CSS-модификатор на основе
`liquidGlassEnabled`. Это не требует передавать настройку через цепочку
`Dashboard → WidgetCanvas → WidgetHost`.

Markdown и Search получают отдельные семантические классы поверхности и общий
класс Liquid Glass. Базовые стили описывают выключенное состояние, а корневой
модификатор включает прозрачность, размытие и блики. Это сохраняет прежний вид
при выключении и позволяет согласованно менять эффект в одном месте.

## Сохранение и совместимость

Переключатель использует существующий `onAppearanceChange`; запись проходит
через `useDashboardConfig` и текущую очередь немедленных сохранений. Новых
ключей хранилища, разрешений Chrome и сетевых запросов не появляется.

Валидатор v4 принимает `liquidGlassEnabled` только как boolean. Миграционные
тесты подтверждают включённое значение по умолчанию для старых схем и
сохранность всех остальных данных.

## Ошибки и доступность

Ошибка сохранения настройки отображается существующим глобальным механизмом и
не требует отдельного сообщения. Переключатель получает доступное имя и
нативную клавиатурную семантику. При `prefers-reduced-motion` эффект остаётся
статическим; новые анимации не добавляются.

## Проверка

Автоматические тесты должны подтвердить:

- миграцию схем v1/v2/v3 в v4 с включённым Liquid Glass;
- отклонение некорректного значения настройки;
- немедленное сохранение переключателя;
- наличие стеклянных классов у Markdown и Search при включённом эффекте;
- возврат прежних поверхностей при выключении;
- сохранение высоты Search в одну строку;
- изначально закрытый раздел «Виджеты»;
- отсутствие регрессий в управлении виджетами и обоями.

Перед завершением выполняются `pnpm lint`, `pnpm typecheck`, `pnpm test`,
`pnpm build` и проверка Prettier. Визуальный smoke-check выполняется в Chrome,
если политика управления разрешает доступ к странице расширения.

## Критерии приёмки

- Обои или цвет фона заметно видны через Markdown и Search.
- Контент остаётся читаемым в светлой и тёмной теме.
- Search визуально является единой стеклянной капсулой и остаётся высотой в
  одну строку.
- Эффект можно полностью выключить в разделе «Виджеты».
- Выбранное состояние восстанавливается после перезапуска Chrome.
- Старые конфигурации мигрируют без потери пользовательских данных.
