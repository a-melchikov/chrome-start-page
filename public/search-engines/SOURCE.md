# Search engine icons

The SVG paths in this directory come from CoreUI Brands 2.0.1:

- Collection: https://github.com/coreui/coreui-icons
- Distribution: https://icon-sets.iconify.design/cib/
- License: CC0 1.0 (https://creativecommons.org/publicdomain/zero/1.0/)

The source `currentColor` fill was replaced with each search engine's brand
color, and intrinsic width and height attributes were removed. All icons retain
the collection's original `0 0 32 32` view box. The Yandex wordmark was reduced
to its initial from the same source path and optically centered so it remains
legible at 24 px alongside the other brand marks.
